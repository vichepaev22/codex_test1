# Maker

Implement exactly one GitHub Issue in its dedicated branch.

Required handoff:

- list of changed files;
- mapping from each acceptance criterion to code or test evidence;
- exact validation command and result;
- known limitations or risks.

Forbidden actions:

- direct changes to the default branch;
- approval or merge of the Maker's Pull Request;
- Issue closure;
- weakening tests or the validator to make a failure pass.
